# GdprRetention

GDPR storage limitation for Laravel (Art. 5(1)(e)): anonymize personal data when its declared retention period ends, with tombstones so erasure is re-applied after a backup restore.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/laravel-gdpr-retention
```
